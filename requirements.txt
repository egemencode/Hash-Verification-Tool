# Hash Verification Tool — runtime dependencies
# ----------------------------------------------------------------------
# Everything below is OPTIONAL. The tool falls back to the standard
# library if a package is missing, so it always runs. Installing the
# full set just gives you a nicer experience:
#
#   requests  : VirusTotal lookups go through requests when available;
#               otherwise we use urllib from the stdlib (slower TLS).
#   windnd    : enables drag-and-drop on the Güven Kontrolü tab.
#               Without it the "Dosya Seç…" button still works.
#   colorama  : ANSI colour output for the legacy CLI (advanced tab /
#               main.py). The GUI does not use it.
#   sv-ttk    : Sun Valley theme — a modern Windows 11 look for the GUI.
#               Without it the GUI falls back to its built-in clam styling.
#
# If you are building an EXE with PyInstaller install all four so the
# bundle ships the best UX out of the box.
# ----------------------------------------------------------------------
requests>=2.31.0
windnd>=1.0.7
colorama>=0.4.6
sv-ttk>=2.6,<3

# cryptography: REQUIRED only for the optional Ed25519 signed-manifest
# feature (core.manifest_signing) — generating a key, signing a manifest,
# and verifying one. Everything else (hashing, verify, VirusTotal, GUI)
# works without it; the module raises a clear error if it is missing.
# Pinned to a major-version range so a future breaking release cannot
# silently change the signing/verification behaviour.
cryptography>=43,<47
